# IntraToCalendar Extension - Session Memory

## What Was Built (March 31, 2026)

Created a complete Chrome extension for extracting dates from web pages and saving to Google Calendar.

### Components Created
- manifest.json (v3, OAuth2 configured)
- content.js (DOM scanning + MutationObserver)
- date-utils.js (6+ date format patterns)
- popup.html/js/css (user interface)
- calendar-utils.js (Google Calendar API)
- ics-utils.js (RFC 5545 .ics export)
- background.js (service worker, OAuth handler)

### Key Features
✅ Multi-format date extraction (handles 6+ common formats)
✅ Smart filtering (ignores prices, IDs, etc.)
✅ User selection with checkboxes
✅ Google Calendar OAuth2 integration
✅ .ics file download (no auth needed)
✅ MutationObserver for dynamic content (React/Vue/Angular)
✅ Edge case handling (no dates, duplicates, 20+ limit)
✅ Security: OAuth2, HTTPS, minimal permissions

## Setup Required Before Use

1. **OAuth2 Configuration** (manifest.json)
   - Need real Google Client ID
   - Replace "YOUR_CLIENT_ID" placeholder
   - See OAUTH_SETUP.md

2. **Extension Icons**
   - Placeholder 1x1 PNGs created
   - Use generate_icons.py for better icons
   - Or use online icon generator

3. **Load in Chrome**
   - chrome://extensions/
   - Developer mode ON
   - Load unpacked
   - Note Extension ID for OAuth

## Architecture Highlights

**Separation of Concerns:**
- Utils modules for reusable logic
- Content script isolated from popup
- Background service for API calls
- Centralized styling

**Security:**
- Chrome Identity API for OAuth
- No third-party servers
- Minimal permissions
- Token caching with expiry
